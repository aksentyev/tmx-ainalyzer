# Железо v1 — макет на DevKit

Статус: черновик, до закупки. Пины C5 — предложение, сверить с pinout ESP32-C5-DevKitC-1.

## Блок-схема

```
                  ┌──────────────────────────────────────────────────────────┐
                  │                      ESP32-C5-DevKitC-1                 │
                  │                                                          │
   I2C (3.3 V) ───┤ SDA/SCL ── ADS1115 ── O2-ячейка (гальв., ~12 мВ)        │
                  │          ├─ SCD30   (CO2 NDIR + RH + T)                  │
                  │          ├─ TMP117  (T газа в трубке)                    │
                  │          ├─ BMP390  (P для компенсации NDIR)             │
                  │          (АКБ — делитель 100k/100k → GPIO5, ADC ESP)     │
                  │                                                          │
   I2S full-dup ──┤ BCLK/WS ── общие                                         │
                  │ DIN  ◄──── ICS-43434  (микрофон в торце B, в газе)       │
                  │ DOUT ────► MAX98357A ── динамик 20 мм 8 Ом (торец трубы) │
                  │            (он же зуммер для UI)                         │
                  │                                                          │
   UART1 ─────────┤ TX/RX ──── ZE15-CO  (CO, UART, питание 5 V)              │
                  │                                                          │
   SPI ───────────┤ SCK/MOSI/DC/RST ── LCD ST7567 128×64 трансфлективный      │
                  │                                                          │
   ADC ───────────┤ 1 канал ── 3 кнопки резисторной лесенкой                 │
                  │                                                          │
   USB-C ─────────┤ USB-serial/JTAG: консоль, прошивка                        │
                  └──────────────────────────────────────────────────────────┘

Питание:  18650 ─ полифьюз ─ TP4056 (+DW01) ─ выкл ─ boost 5 V (≥1 A) ─┬─ 5 V: ZE15-CO, MAX98357A
                                                                       ├─ Шоттки ─► пин 5V девкита
                                                                       │   (его LDO питает сам C5)
                                                                       ├─ LDO 3.3 V ≥800 mA (AMS1117): периферия
                                                                       └─ феррит ─ LP5907-3.3 → +3V3A: ADS1115, микрофон
```

Питание девкита — через его пин 5V за Шоттки: при подключённом USB VBUS (5.0 V) выше нашего
(≈4.7 V после диода), диод закрыт, девкит ест USB, периферия — от АКБ. Так можно отлаживать с
батареей и USB одновременно без встречного питания. Внешнюю 3.3 V на пин 3V3 девкита **не
подавать**.

LDO: AP2112K — 600 mA, не хватит; AMS1117-3.3 (1 A) на модуле при 5→3.3 V и ~400 mA греется
на ~0.7 Вт — терпимо. v2: buck 3.3 V вместо «boost→LDO» (КПД 66 % на этой ветке).

TP4056 без load-sharing: заряжать **выключенным** прибором, иначе зарядка не завершится по
току. v2 — P-MOSFET + диод (стандартная схема load-sharing).

## Пневматика

```
Вентиль баллона (DIN 200/300 бар) ─ O2-clean ограничитель потока ~1 л/мин ─ шланг 1–1.5 м
   ─ медный змеевик Ø4 × ~50 см, намотан на резонатор (термализация)
   ─ акустическая трубка (вход торец A → выход торец B)
   ─ камера O2-ячейки (в ней же BMP390)
   ─ колпак SCD30 ─ колпак ZE15-CO (диффузионный, без струи на сенсор) ─ выхлоп (короткий, свободный)
```

Порядок: змеевик **первый**, чтобы холодный газ не попадал ни на гальваническую ячейку
(её термокомпенсация инерционна), ни в резонатор; O2-ячейка — сразу после трубки, газ там уже
при температуре резонатора. SCD30 и ZE15 требуют своих проточных колпаков с портами 4 мм —
в BOM. ZE15 нельзя обдувать струёй; прогрев 30 с (первое включение — 5 мин);
его отклик ≤30 с.

Всё после ограничителя — при атмосферном давлении. BMP390 стоит в тракте и контролирует,
что избытка нет (гальваническая ячейка и NDIR под давлением врут).

Дросселирование 200 бар → 1 атм в одну ступень (Джоуль–Томсон интегрально): воздух/найтрокс
−30…−40 °C, O2 −40…−50 °C, He **+10 °C** (инверсионная T ~40 K). Змеевик как теплообменник:
ламинарный поток в Ø3 мм, Nu≈3.66, h≈32 Вт/м²К; 50 см меди → hA≈0.15 Вт/К при теплоёмкостном
расходе газа 0.02 Вт/К → NTU≈7.5 → остаток <0.05 °C. 30 см даёт ~0.4 °C — мало.
Тепловая нагрузка на резонатор ≈0.8 Вт, труба за замер уедет на ~0.5 °C — не страшно, пока
TMP117 стоит в потоке после змеевика и меряет то же, что видит газ. v2: канал в точёной заглушке.

Расход через ограничитель-отверстие ∝ давлению в баллоне (200 бар vs 50 бар — 4×) и для He
~3× выше по объёму, чем для воздуха. Время продувки плавает 10–40 с: UI показывает стабилизацию,
а не таймер. Выход ячейки короткий и широкий, иначе давление в тракте поднимется.

Безопасность: ограничитель и всё до него видит 200 бар чистого O2 — только покупной O2-clean
DIN (латунь/нержавейка, без углеводородной смазки). Никакого DIY до ограничителя.

## Акустическая ячейка

Подробно — `cell.md`. Кратко: медь T2 Ø25×1.5 (канал 22), трубка 180 мм, пробки по 15 мм → **L_ак = 150 мм**;
O-ring 18×2; динамик 20 мм стоит в канале перед пробкой A, газ входит за ним и идёт по ободу —
нет мёртвого объёма; микрофон в центре торца B; TMP117 в выходной камере пробки B.
f₁: 1144 Гц воздух → 3358 Гц He.

## Распиновка (проверено по даташиту ESP32-C5 v1.5 и гайду DevKitC-1)

Факты по чипу:
- 29 GPIO (0–28). На гребёнки DevKitC-1 выведены: 0–14, 23–28 (+15 только без PSRAM; у N8R8 занят).
- GPIO16–22 — flash/PSRAM, не выведены. GPIO13/14 — USB D−/D+ (консоль и прошивка).
- ADC: **один** 12-бит SAR, 6 каналов — GPIO1–6 (ADC1_CH0–CH5). ADC2 нет → конфликта с Wi-Fi нет.
- Аналоговый компаратор: PAD_COMP0 = GPIO8, PAD_COMP1 = GPIO9.
- Один I2S-контроллер, **full-duplex подтверждён**: TX и RX на одном порту с общими BCLK/WS,
  `i2s_new_channel()` отдаёт оба хэндла за один вызов. PDM RX есть (без аппаратного PDM→PCM), TDM есть.
- Strapping (даташит, таблица 3-1): GPIO2 (MTMS), GPIO3 (MTDI), GPIO7, GPIO25, GPIO26, GPIO27, GPIO28.
  IDF-страница GPIO для esp32c5 сама список не даёт, отсылает к даташиту; в пинах J1/J3 гайда
  девкита помечены все семь.
- В даташите в одном месте написано «GPIO27: the VDD_SPI pin» — опечатка (VDD_SPI = GPIO19 по
  Table 7-1); на DevKitC-1 GPIO27 — обычный IO, ведёт на WS2812.
- GPIO4 (MTCK) после сброса имеет слабую подтяжку вверх — до init ADC-драйвера лесенка покажет
  ~0.6 V; `adc_oneshot` подтяжку снимает.

Что каждый strapping-пин делает и можно ли его трогать:

| GPIO | Функция при сбросе | Default | Вердикт |
|---|---|---|---|
| 28 | Boot mode (0 = download) | pull-up | **не трогать** — это кнопка BOOT |
| 26, 27 | Boot mode, но учитываются только при GPIO28=0; 27 ещё ROM-print (eFuse=0 → не влияет) | 26 float, 27 pull-up | ок для выходов на Hi-Z входы (LCD DC/RST). 27 на девките ещё ведёт на RGB LED |
| 25, 3 | Только фронт SDIO-клока; SDIO не используем | float | **безопасны** |
| 7 | Источник JTAG; внутренних подтяжек нет, «должен управляться внешней цепью» | — | не трогать |
| 2 | MTMS, в таблицах boot-параметров не фигурирует | float | резерв, только Hi-Z нагрузка |

Консоль — на USB-Serial/JTAG (`CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG`), UART0-пины 11/12 свободны.

| Функция | GPIO | Примечание |
|---|---|---|
| I2C SDA | 0 | 100 кГц — ограничение SCD30 |
| I2C SCL | 1 | |
| UART1 RX ← ZE15 TX | 2 | strapping MTMS без boot-функции; ZE15 TX = 3.0 V — ок для VIH 2.48 V |
| SPI SCK | 3 | strapping — безопасен (SDIO) |
| Кнопки (ADC1_CH3) | 4 | лесенка 3 кнопки |
| АКБ (ADC1_CH4) | 5 | делитель 100k/100k + 100 нФ; 4.2 V → 2.1 V |
| I2S BCLK | 6 | общий TX/RX |
| — | 7 | не использовать (JTAG strap) |
| **резерв PAD_COMP0/1** | 8, 9 | под план Б — ToF с аппаратным компаратором |
| I2S WS | 10 | общий TX/RX |
| UART1 TX → ZE15 RX | 11 | через делитель 1k/4.7k → 2.72 V (вход ZE15 0–3.0 V). U0TXD: сюда сыплется ROM-лог при сбросе; ZE15 битые кадры игнорирует |
| LCD BL | 12 | PWM подсветки; на солнце гасить — трансфлективный читается без неё |
| USB D−/D+ | 13, 14 | консоль, прошивка |
| I2S DIN (мик) | 23 | |
| I2S DOUT (усилитель) | 24 | |
| SPI MOSI | 25 | strapping — безопасен (SDIO) |
| LCD DC (RS/A0) | 26 | strapping — Hi-Z нагрузка, ок |
| LCD RST | 27 | strapping, pull-up на плате; на девките ещё WS2812 — при дёргании RST мигнёт, безвредно |
| — | 28 | BOOT, не использовать |

Почему UART RX **не на GPIO12**: это U0RXD, в download-режиме ROM слушает и UART0; ZE15 по
умолчанию шлёт кадр каждую секунду и может сбить сессию esptool. Поэтому RX на GPIO2, а
GPIO12 отдан под подсветку.

Задействовано 16, свободны 8/9 (компаратор). LCD CS — на GND (единственный slave).
