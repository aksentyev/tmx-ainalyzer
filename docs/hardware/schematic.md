# Принципиальная схема v1 (макет на модулях)

Схема по листам, как будет в KiCad. Все элементы — готовые breakout-модули на макетке/перфоплате,
дискретные компоненты — только обвязка между ними. Имена цепей (нетов) единые по всем листам
и в нетлисте в конце.

Соглашения:
- `+VBAT` — аккумулятор после защиты и выключателя (3.0–4.2 V)
- `+5V` — выход boost
- `+3V3` — выход нашего LDO (периферия). **Не** 3V3 девкита.
- `GND` — общая земля, одна точка звезды на перфоплате у LDO
- Пины девкита — `GPIOn`; пины модулей — по шелкографии модуля

## Лист 1 — Питание

```
                 F1 полифьюз 1.5 A
  18650 (+) ──────[====]──────┐
                               │  B+        TP4056 + DW01/FS8205          OUT+ ──┐
  18650 (−) ───────────────────┼─ B−        (модуль с USB-C)              OUT− ──┼─ GND
                               │            IN+/IN− ← USB-C зарядки              │
                               │                                                 │
                               │                        SW1 SPDT            ┌────┘
                               │                       ┌──o  o──── +VBAT ───┤
                               └───────────────────────┘                     │
                                                                             │
  +VBAT ──┬──────────────────────────────────────────────┐                   │
          │                                              │                   │
          │   U1 boost 5 V ≥1 A (MT3608, выставить        │  делитель АКБ:    │
          │      5.2 V — ZE15 требует ≥5.0 V)             │  +VBAT ─ R40 100k ─┬─ GPIO5 (ADC1_CH4)
          │   VIN ── +VBAT        VOUT ── +5V            │          R41 100k ─┤
          │   GND ── GND                                 │          C40 100 nF┤
          │                                              │                    GND
          │
  +5V ──┬─────────┬──────────────┬──────────────────┬───────────────────────────
        │         │              │                  │
        │   C1 220 µF/10 V    U2 AMS1117-3.3    D1 1N5819 ──► пин «5V» девкита
        │   (у MAX98357A)     IN ── +5V          (анод к +5V, катод к девкиту)
        │                     OUT ── +3V3
        │                     GND ── GND
        │                                  C2 100 µF/6.3 V  +3V3 ── GND  (у девкита/перфоплаты)
        │
        └── потребители 5 V: MAX98357A VIN, ZE15 Vin (через D2, лист 6)

  +3V3 потребители: SCD30, TMP117, BMP390, LCD ST7567, подтяжки I2C, лесенка кнопок

  Аналоговая шина (единственное аналоговое место прибора — 12 мВ ячейки на ADS1115):
  +5V ── FB1 феррит 600 Ω@100 МГц ── U3 LP5907-3.3 (или TPS7A20-3.3) ── +3V3A ── ADS1115 VDD, ICS-43434 VDD
                                      C4 1 µF вход, C5 1 µF выход (керамика, у U3)
  LP5907: 6.5 µV RMS, PSRR 80 dB — от импульсного boost и class-D усилителя на ADS1115 ничего не доходит.
  От +3V3 (AMS1117) питать нельзя — LDO нужен запас по входу, поэтому от +5V.
```

Пояснения:
- D1 развязывает нашу +5V с USB VBUS девкита. USB подключён → VBUS 5.0 V > 4.7 V за диодом →
  D1 закрыт, девкит ест USB, периферия — от АКБ. USB отключён → девкит от +5V через D1 (4.7 V на
  входе его LDO — достаточно для 3.3 V).
- Пин «3V3» девкита **ни с чем не соединять**, кроме как измерить.
- Земля — звездой на перфоплате у U2: силовая земля (boost, MAX98357A, ZE15) и земля датчиков
  (ADS1115, ячейка, микрофон) сходятся в одной точке; обратный ток усилителя не течёт через землю ячейки.
- TP4056 без load-sharing → заряжать выключенным (SW1 off).
- Бюджет тока — в конце документа.

## Лист 2 — MCU: ESP32-C5-DevKitC-1

Только используемые пины; остальные NC. Нумерация — GPIO, не номер пина гребёнки.

```

         +5V (за D1)─┤ 5V                       GND ├─ GND
                     │                              │
            SDA ─────┤ GPIO0                  GPIO2 ├───── UART_RX_ZE   (← ZE15 TXD, через R10)
            SCL ─────┤ GPIO1                  GPIO3 ├───── SPI_SCK
        ADC_BTN ─────┤ GPIO4                  GPIO5 ├───── (резерв, ADC1_CH4)
       I2S_BCLK ─────┤ GPIO6                  GPIO7 ├───── NC (JTAG strap)
   PAD_COMP0 рез.────┤ GPIO8                  GPIO9 ├───── PAD_COMP1 резерв
         I2S_WS ─────┤ GPIO10                GPIO11 ├───── UART_TX_ZE   (→ делитель → ZE15 RXD)
```

Последовательные резисторы на I2S (R20–R22, 33 Ω) ставятся у девкита — см. лист 5.

## Лист 3 — Шина I2C и датчики на ней

```
  +3V3 ──┬── R1 4.7k ──┐
         └── R2 4.7k ──┼──┐
                       │  │
  GPIO0 ─── SDA ───────┴──┼────┬──────────┬──────────┬──────────┬──────────┐
  GPIO1 ─── SCL ──────────┴────┼────┬─────┼────┬─────┼────┬─────┼────┬─────┼────┐
                               │    │     │    │     │    │     │    │     │    │
                             SDA  SCL   SDA  SCL   SDA  SCL   SDA  SCL   SDA  SCL
                            ┌─────────┐┌─────────┐┌─────────┐┌─────────┐┌─────────┐
                            │ ADS1115 ││  SCD30  ││ TMP117  ││ BMP390  ││ резерв  │
                            │  0x48   ││  0x61   ││  0x49   ││  0x77   ││(ADS1220)│
                            └─────────┘└─────────┘└─────────┘└─────────┘└─────────┘
   питание:                  +3V3A/GND  +3V3/GND   +3V3/GND   +3V3/GND   —
   конфиг:                   ADDR→GND   SEL→GND    ADD0→V+    SDO откр.  —
                             ALERT NC   RDY NC     ALERT NC   CS откр.
                                        PWM NC                (I2C по умолч.)
```

- Скорость шины **100 кГц** (ограничение SCD30), clock stretching включён, таймаут ≥20 мс.
- Подтяжки: перед установкой R1/R2 посчитать, что уже стоит на модулях (ADS1115-модуль обычно
  10k, TMP117/BMP390 брейкауты — 10k). Цель: суммарно 2.2–4.7k.
  Если на модулях набирается ≥3 × 10k, R1/R2 не ставить.
- SCD30 — **опция** (decisions D17); если ставим — на отдельном JST-PH 4, кабель ≤15 см. Без него
  шина свободна от ограничений 100 кГц / clock stretching / no repeated start.
- TMP117 — в пробке B ячейки, кабель 4 жилы ≤15 см, JST-PH 4.
- BMP390 — в камере O2-ячейки.

## Лист 4 — O2: гальваническая ячейка → ADS1115

```
   O2-ячейка (R-22D / PSR-11-39-MD, внутри уже нагрузочный резистор и термокомпенсация)
   разъём: JST-PH 2 (на ячейке — Molex, переходник)

     (+) ──── R3 470 Ω ────┬──── AIN0 ┐
                           │          │  ADS1115, PGA ±256 mV (gain 16), диф. AIN0−AIN1
                        C3 220 nF     │  128 SPS, непрерывный режим
                        C0G/плёнка    │
                           │          │
     (−) ──┬─ R4 470 Ω ────┴──── AIN1 ┘
           │
          GND                       AIN2, AIN3 — NC (или резерв под вторую ячейку)
```

- Ячейка даёт +7…+14 mV в воздухе, ~+50…+65 mV в 100 % O2 → в ±256 mV с запасом, LSB 7.8 µV →
  ~0.07 % O2 на отсчёт, с шумом ±2–3 LSB ≈ 0.1–0.2 % без усреднения; усреднение 1 с → 0.05 %.
  Апгрейд — ADS1220 (24 бит, PGA 128): 0.01 %, тот же I2C-разъём. Питание — +3V3A.
- Минус ячейки на GND задаёт синфазный уровень; измерение дифференциальное, чтобы не ловить
  падение на земляных проводах.
- fc фильтра ≈ 770 Гц; суммарно 940 Ω последовательно при входном импедансе 710 kΩ → ошибка
  усиления 0.13 %, уходит в калибровку.
- **Ничего параллельно ячейке не вешать** — нагрузка уже внутри.

## Лист 5 — Акустика: I2S full-duplex

```
                       R20 33 Ω
  GPIO6  I2S_BCLK ────[===]────┬──────────────────────────► SCK   ICS-43434 (пробка B)
                               └──────────────────────────► BCLK  MAX98357A
                       R21 33 Ω
  GPIO10 I2S_WS ──────[===]────┬──────────────────────────► WS    ICS-43434
                               └──────────────────────────► LRC   MAX98357A

  GPIO23 I2S_SD_MIC ◄──────────────────────────────────────  SD    ICS-43434
                       R22 33 Ω
  GPIO24 I2S_SD_AMP ──[===]───────────────────────────────►  DIN   MAX98357A

  ICS-43434:  VDD ── +3V3A  GND ── GND   L/R ── GND (левый слот)
              кабель 5 жил ≤15 см, JST-PH 5, витая с GND

  MAX98357A:  VIN ── +5V (C1 220 µF рядом)   GND ── GND
              GAIN ── R23 100k ── VIN   (3 dB; без R23 = 9 dB)
              SD   ── R24 1 MΩ ── VIN   (режим (L+R)/2; на Adafruit-модуле уже стоит)
              +  ── SPK+ ───► динамик Ø20 8 Ω (пробка A), кабель 2 жилы ~25 см, JST-PH 2
              −  ── SPK−
```

- R20–R22 гасят звон на проводах при BCLK 3.072 МГц; ставить у девкита.
- 48 кГц / 32 бит, TX и RX на одном порту (`i2s_new_channel()` с обоими хэндлами).
- Усилитель на +5V — ради запаса по амплитуде; но в прошивке −6 dB, чтобы не спалить динамик.

## Лист 6 — CO: ZE15-CO (UART)

Распиновка по даташиту ZE15-CO (2023, 15-pin), совпадает с ZE15: PIN15 Vin 5–12 V; PIN5, PIN14 GND;
PIN7 RXD (0–3.0 V); PIN8 TXD (0–3.0 V); PIN10 DAC 0.4–2 V (не используем); PIN1 — выход 3.0 V
(не используем); **PIN3 — «неисправность сенсора», меандр 1 Гц 10 %** — опционально на свободный
GPIO (12 при BL на +3V3). Прогрев 30 с, отклик ≤30 с (у ZE15 было 3 мин / 60 с).
**Сверить с шелкографией конкретного модуля перед пайкой.**

```
                       D2 1N5819
  +5V ────────────────►|───────── PIN15 Vin        (защита от переполюсовки — своей у ZE15 нет)
                                  PIN5  GND ── GND
                                  PIN14 GND ── GND

                  R11 1k
  GPIO11 UART_TX_ZE ──[===]───┬── PIN7 RXD          V = 3.3·4.7/5.7 = 2.72 V  (вход 0–3.0 V)
                              │
                           R12 4.7k
                              │
                             GND

                  R10 1k
  GPIO2  UART_RX_ZE ◄─[===]────── PIN8 TXD          3.0 V → VIH ESP 2.48 V, ок
```

- 9600 8N1. По умолчанию active upload раз в секунду; при старте переводим в Q&A
  (кадр `FF 01 78 41 00 00 00 00 46`), опрос `FF 01 86 00 00 00 00 00 79`. Протокол — в
  `docs/firmware/notes.md`.
- Vin 5 V минус 0.3 V на D2 = 4.7 V — в диапазоне 5–12 V? **Нет**, 4.7 < 5.0. Варианты:
  (а) Шоттки с малым падением (PMEG2010, ~0.2 V → 4.8 V, всё ещё ниже); (б) убрать D2 и
  защититься механически — ключевой разъём JST-XH; (в) питать ZE15 напрямую с +5V и поднять
  boost до 5.2 V. **Выбор v1: (б) + (в)** — boost выставить 5.2 V, D2 не ставить, разъём с ключом.
  MAX98357A и девкит 5.2 V переносят.

## Лист 7 — UI: дисплей и кнопки

```
  LCD ST7567 128×64, SPI 4-wire, трансфлективный (GMG12864-06D / ERC12864, 3.3 V)
      GND ── GND
      VCC ── +3V3
      SCL/SCK ── SPI_SCK   (GPIO3)
      SI/SDA  ── SPI_MOSI  (GPIO25)
      RSE/RST ── LCD_RST   (GPIO27)
      RS/A0   ── LCD_DC    (GPIO26)
      CS      ── GND       (единственный slave; если модуль не терпит — на свободный GPIO)
      LED+/BL ── R33 (по току подсветки модуля, обычно уже стоит) ── LCD_BL (GPIO12, PWM)
      LED−    ── GND
  Названия пинов у модулей гуляют (SCL/SCK, SI/SDA, RSE/RST, RS/A0) — сверять с шелкографией.
  Контраст (регистр EV) зависит от температуры — компенсировать по TMP117/BMP390.

  Кнопки, резисторная лесенка на ADC1_CH3:

  +3V3 ──┬── SW_A ──── 0 Ω ────┐
         ├── SW_B ─── R31 4.7k ─┤
         └── SW_C ─── R32 15k ──┤
                                ├──── GPIO4 ADC_BTN
                   R30 10k ─────┤
                   C30 100 nF ──┤
                               GND

  Уровни: A = 3.3 V (насыщение, норм), B = 2.24 V, C = 1.32 V, ничего = 0 V.
  Пороги в прошивке: >2.8 → A, 1.8–2.8 → B, 0.6–1.8 → C, <0.6 → нет.
  Одновременные нажатия не различаются — не нужны.
```
