# Заметки по прошивке (идеи до реализации)

## Критерий стабилизации показаний — по производной, а не по таймеру

Расход через ограничитель-отверстие ∝ давлению в баллоне (4× между 200 и 50 бар) и ~3× выше
для He, чем для воздуха. Время продувки плавает 10–40 с, поэтому фиксированный таймер не работает.

Правило: показание считается стабильным, когда за скользящее окно ~5 с
- резонансная частота f ушла меньше чем на порог (≈0.5 Гц ≈ 0.05 % He),
- O2 ушёл меньше чем на 0.1 %,
- T газа ушла меньше чем на 0.2 °C.

UI показывает «стабилизация…» с индикатором тренда, потом фиксирует результат. Это ещё и
защита от «снял показания, пока гелий не доехал». То же правило для CO2/CO, со своими порогами.

## Консоль и UART

Консоль на USB-Serial/JTAG (`CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y`), чтобы освободить GPIO11/12
под UART1 для ZE07-CO. ROM-бутлоадер всё равно печатает в U0TXD (GPIO11) при сбросе — ZE07
битые кадры игнорирует, но парсер ответов ZE07 должен быть терпим к мусору в первые ~0.5 с.

## I2S full-duplex

Один контроллер, `i2s_new_channel()` с обоими хэндлами; общие BCLK/WS, одинаковые sample rate и
bits-per-frame у TX и RX. 48 кГц / 32 бит (ICS-43434 отдаёт 24 в 32-битном слоте; MAX98357A ест
16/24/32). DOUT — чирп/шум, DIN — микрофон, захват синхронный по одному клоку — задержка между
ними детерминирована, что важно для корреляции.

## Распознавание гребёнки

Не следить за одним пиком — свипить широко (0.5–8 кГц чирпом/шумом, ~1 с), находить все пики,
проверять равный шаг Δf = c/2L и опознавать номер моды n. Воздух: Δf≈1143 Гц, He: ≈3357 Гц.
Потом — узкое слежение за одним пиком (3–10 Гц обновление).

## Пики трубки vs горб динамика

У 20-мм динамика свой резонанс (~1 кГц, Q≈2) — широкий горб в передаточной функции.
Резонансы трубки узкие (Q≈50–100). Искать пики относительно локального baseline (median filter
по спектру), не по абсолютному уровню.
