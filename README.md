# tmx analyzer

DIY-анализатор тримикса для дайвинга: **O2, He, CO2, CO** в одном приборе.
He измеряется акустически — по резонансной частоте закрытой трубки (скорость звука в смеси),
без расходного He-датчика. Мозги — ESP32-C5 на ESP-IDF.

## Ключевые числа

- Трубка Cu Ø25×1.5, L=180, пробки по 15 → L_ак ≈ 145.5 мм. f₁: воздух ≈1180 Гц, He ≈3460 Гц.
- Цель по He: 0.1 % абс. Чувствительность 5.5–12.5 Гц на 1 % He; T газа нужна с ±0.3 °C (0.171 %/°C).
- Пограничный слой Кирхгофа: до ~1 % He систематики без двухточечной калибровки (воздух + He).
- Калибровочные газы в наличии: воздух, Nx50, 100 % O2. He — достать.
- Бюджет железа v1 ≈ $340–420.

## Быстрый старт

```
brew install --cask openscad@snapshot      # стабильный cask отключён, снапшот ок
cd hardware/scad && ./render.sh            # STL + превью всех деталей
```

Перед печатью — пройти по пометкам **ИЗМЕРИТЬ** в `hardware/scad/params.scad`.
