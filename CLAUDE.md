# Правила работы с репозиторием

## Контекст

Хобби-проект одного человека: анализатор тримикса (O2/He/CO2/CO) на ESP32-C5. Автор —
технический дайвер, разбирается в электронике и embedded. Общение и документация — **по-русски**.
Идентификаторы в коде — английские; комментарии в `.scad` и docs — русские.

Перед тем как что-то предлагать, прочитать `docs/decisions.md`: там зафиксированы решения
и отвергнутые альтернативы. Не предлагать заново Arduino, ESP32-C3/S3, TC-датчик гелия, ToF
как основной метод, TFT-дисплей, фитинги M5 — если нет новых фактов.

## Как работать

- **Сначала обсудить, потом писать файлы.** Автор предпочитает двигаться по шагам
  («сначала ячейка, потом пины») и останавливает, если файлы появляются раньше согласия.
- На хардверные вопросы отвечать с числами и расчётами, а не общими словами.
- Не забывать мелочёвку (резисторы, конденсаторы, стабилизаторы, разъёмы) — автор просил явно.
- Любая существенная работа по железу/печатным деталям/прошивке перед мержем проходит
  **ревью отдельным субагентом с чистым контекстом**, которому даётся доступ к даташитам
  (WebFetch/WebSearch) и инструментам (openscad, разрезы). Отчёт разбирается пунктами: что
  принято, что нет и почему. Прошлые ревью нашли по 4–5 блокеров каждое — это окупается.
- После правок SCAD: `./render.sh`, убедиться `Status: NoError`, посмотреть превью и разрезы
  (Read на PNG) — внутренние полости снаружи не видны.

## Git

- Коммиты — на ветке (`docs/…`, `hw/…`, `fw/…`), затем `git checkout main && git merge --ff-only`,
  ветку удалить, `git push origin main`. Напрямую в `main` не коммитить.
- Сообщения коммитов по-русски, кратко, с заключительной строкой
  `Co-Authored-By: Claude <модель> <noreply@anthropic.com>`.
- `hardware/stl/` не коммитится (в `.gitignore`) — это производные от `.scad`.
- Remote: `origin` = `git@github.com:aksentyev/tmx-ainalyzer.git` (да, «ainalyzer» — не опечатка).

## Окружение (macOS)

- `openscad` (snapshot, Manifold) в PATH; `rsvg-convert` для SVG→PNG; `qlmanage` обрезает края.
- Python 3.9 системный, **без numpy/scipy**; есть `pypdf` (user site). Для `tools/gasmodel` —
  чистый stdlib или завести venv.
- ESP-IDF **не установлен**; `clang`, `make` есть, `cmake` нет. Хост-тесты DSP — на clang.
- `gh` нет; GitHub по SSH работает.
- Скачанные даташиты класть в scratchpad, текст вытаскивать `pypdf`; `pdftotext` нет.

## Безопасность

Всё до DIN-ограничителя потока видит 200 бар чистого O2. Не предлагать там DIY, смазки,
пластик, игольчатые вентили с Ali — только покупной O2-clean ограничитель.
