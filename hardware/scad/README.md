# Печатные детали (OpenSCAD)

Параметрические модели всех печатных деталей v1. Все размеры — в `params.scad`; детали
подхватывают их через `include`. Перед печатью пройти по пометкам **ИЗМЕРИТЬ** в `params.scad`
и вбить реальные размеры модулей.

```
brew install --cask openscad@snapshot    # стабильная 2021.01 отключена в Homebrew, снапшот — ок
./render.sh                              # все детали → ../stl/*.stl (binstl) + ../stl/preview/*.png
./render.sh plug_a plug_b                # выборочно
```

Пробки рендерятся во всех вариантах зазора из `plug_fits`: `plug_a_f02.stl`, `plug_a_f04.stl`,
`plug_a_f06.stl` и т.д. STL и превью не коммитятся (`hardware/stl/` в .gitignore).

древовидные поддержки «только от стола», иначе низ будет с бахромой. У остальных деталей
ёлочки выше — печатаются без поддержек.

## Логика посадки пробок

Пробка Ø = `bore_d − fit`. Печатаем **тест-кольца первыми, в одном задании с пробками во всех
трёх вариантах**: кольцо, которое село в трубку с ощутимым, но не чрезмерным усилием (с надетым
O-ring 18×2), определяет `fit`; пробки с другим зазором — в мусор. Одна поездка вместо трёх.
Зазор 0.0 исключён: PETG даёт +0.1…0.2 по наружному Ø.

O-ring 18×2: дно канавки задаётся **от канала** (`groove_bottom_d = bore_d − 2·0.8·2 = 18.8`),
поэтому обжатие 20 % при любом `fit`; натяг по ID 4 %. Ширина 2.7, фаска 45° на нависающей
стенке канавки. Если фактический канал ≥22.3 — взять 19×2.

## Что проверить при первой сборке

- Пробка A: динамик приклеен к бобышкам задней стороной, диффузор в трубу. Центровать, вставив
  пробку в тест-кольцо как кондуктор — сам динамик ничем не центрируется. Перед приклейкой
  повернуть бобышки мимо паек/лепестков на тыльной стороне корзины. Дунуть в ёлочку при
  вставленной пробке — выход у торца.
- Пробка B: плата микрофона в углублении **портом к газу**, компонентами к пробке; провода в
  отверстие Ø3.5 у края платы. Если плата — INMP441 (14×11), не влезет: брать брейкаут
  ≤10.5×10.5. Порт микрофона на брейкаутах часто смещён от центра платы — для подавления
  поперечной моды он должен быть ≤2 мм от оси трубки; при необходимости сдвинуть углубление.
- Пробка B: TMP117 лежит на дне кармана сенсором вверх, каналы над платой; провода через паз
  (+X) наружу; крышка `tmp_cover` на RTV по периметру. **Карман не заливать.**
- Камера O2: плечо ячейки давит на O-ring 21×2 в канавке на дне, крышка дожимает за счёт
  `cell_press = 1.2`. BMP390 — сенсором вниз на полку над газовой полостью, эпоксидка по
  периметру платы, затем заливка сверху.
- Коробка SCD30: модуль лежит на 4 угловых столбиках **отверстиями вниз** (они снизу платы),
  выводы — к пазу в длинной стенке; паз и крышку — на термоклей.
- Стакан ZE07: надевается на сенсор с зазором 0.3 на сторону, кромка на 2 мм над платой —
  валик нейтрального RTV по кромке на тело сенсора.
- Все газовые полости пробок изнутри промазать тонким слоем эпоксидки (микропоры PETG).

## Настройки печати

PETG, сопло 0.4, слой 0.2, 5 периметров, 6 слоёв верх/низ, заполнение 30 % (стенки важнее),
поддержки — только от стола под ёлочки пробок. Суммарно ~4 ч на Bambu с 0.4. Все детали
помещаются на 256×256 за один заход.
