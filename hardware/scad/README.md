# Печатные детали (OpenSCAD)

Параметрические модели всех печатных деталей v1. Все размеры — в `params.scad`; детали
подхватывают их через `include`. Перед печатью пройти по пометкам **ИЗМЕРИТЬ** в `params.scad`
и вбить реальные размеры модулей.

```
brew install --cask openscad@snapshot    # стабильная 2021.01 отключена в Homebrew, снапшот — ок
./render.sh                              # все детали → ../stl/*.stl + ../stl/preview/*.png
./render.sh plug_a plug_b                # выборочно
```

STL и превью не коммитятся (`hardware/stl/` в .gitignore) — они производные.

4×6 не влияет.

## Логика посадки пробок

Пробка Ø = `bore_d − fit`. Печатаем **тест-кольца первыми, в одном задании с пробками во всех
трёх вариантах** (`plug_fits`): кольцо, которое село в трубку с ощутимым, но не чрезмерным
усилием (с надетым O-ring 18×2), определяет `fit`; пробки с другим зазором — в мусор. Так одна
поездка к принтеру вместо трёх. Для варианта пробки менять параметр вызова: `plug_a(fit=0.0)`.

O-ring 18×2 в канавке шириной 2.7, глубиной 1.6 (дно Ø ≈ 18.6 при пробке 21.8): натяг ~4 %,
обжатие ~20 %. Если фактический канал ≥22.3 — взять 19×2.

## Что проверить при первой сборке

- Пробка A: динамик приклеен к бобышкам задней стороной, диффузор в трубу, зазор по ободу
  ~1 мм — газ должен проходить (дунуть в ёлочку при вставленной пробке — выход у торца).
- Пробка B: плата микрофона лежит в углублении **портом к газу**, компонентами к пробке.
  Если плата — INMP441 (14×11), она не влезет в Ø21.8 без конфликта с канавкой: брать
  брейкаут ≤10.5×10.5 или увеличить `mic_recess` только по одной оси и проверить рендер.
- Пробка B: TMP117 в кармане, сенсор в потоке; после распайки залить карман эпоксидкой/термоклеем
  заподлицо.
- Камера O2: плечо ячейки давит на O-ring 20×2; если ячейка короче `cell_h`, крышка не прижмёт —
  поправить `cell_h` или подложить шайбу.
- Все газовые полости изнутри промазать тонким слоем эпоксидки (микропоры PETG) — по желанию,
  но для He-канала (пробки) рекомендую.

## Настройки печати

PETG, сопло 0.4, слой 0.2, 5 периметров, 6 слоёв верх/низ, заполнение 30 % (стенки важнее),
без поддержек. Суммарно ~3.5 ч на Bambu с 0.4. Все детали помещаются на 256×256 за один заход.
